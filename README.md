# ExcelDashboard-Project
🚀 Microsoft Excel Data Analytics Project | Sales Analysis Dashboard 📊

I'm excited to share my latest Sales Analysis Dashboard built in Microsoft Excel, designed to transform raw sales data into actionable business insights through interactive visualizations and dynamic reporting.

This dashboard enables stakeholders to monitor sales performance, profitability, regional trends, customer segments, and product categories using interactive filters for Region, Year, and Month.

📌 Key KPIs
💰 Total Sales: $2.30M
📈 Total Profit: $286K
📊 Profit Margin: 12.47%
📦 Total Quantity Sold: 37,873 Units
🔍 Dashboard Insights
Regional analysis highlights West as the top-performing sales region.
Consumer segment contributes the highest share of overall sales.
Technology leads product category sales, followed by Furniture and Office Supplies.
Monthly sales peaked in November and December, indicating strong year-end demand.
Top-performing cities include New York City, Los Angeles, Seattle, and San Francisco.
Standard Class dominates shipping mode usage, offering insights into customer delivery preferences.
Daily sales tracking helps identify peak sales days for better operational planning.
